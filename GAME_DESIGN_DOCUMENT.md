# Game Design Document

## Status

Draft placeholder. This document becomes the executable design specification in Phase 1 after Phase 0 approval.

## Confirmed Constraints

- Android portrait 2D game.
- First playable contains one island and level, three parameters (Hunger, Rest, Fun), touch/mouse controls, pause/restart, timer/score/best score, simple UI, basic animations, and placeholder art.
- Excludes monetization, analytics, online, social, account, shop, cosmetics, and multiple islands.

## Pending Source-Dependent Sections

Core fantasy, player role, activity set, world rules, loop, objective, fail/success states, parameter behavior, scoring, timing, feedback, narrative, art direction, audio direction, and accessibility requirements require the original concept PDF.
